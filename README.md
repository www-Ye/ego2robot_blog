# Ego2Robot

Project page for **Ego2Robot: Scalable Robot Data Synthesis from Egocentric Human Data**.

Converting ~1,940 hours of egocentric human manipulation video into 18,561 hours of robot training data across 15 morphologies, and evaluating its out-of-distribution generalization benefits for VLA policies.

## Local preview

```bash
python3 -m http.server 8000
# open http://127.0.0.1:8000/
```

## Hosting (GitHub Pages)

This is a static site (`index.html` + `style.css` + `assets/`). Enable **Settings → Pages → Source: main / root** to publish at `https://<user>.github.io/ego2robot/`.
